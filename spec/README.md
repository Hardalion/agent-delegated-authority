# ADAP protocol specification

Public draft requirements for the **Agent Delegated Authority Protocol**.

ADAP defines how delegated authority is bounded, evaluated, exercised, and evidenced between autonomous agents. It does not replace identity providers, OAuth, agent frameworks, or execution runtimes. It is not a description of Hardalion Nexus production deployment.
